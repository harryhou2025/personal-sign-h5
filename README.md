# 个人签名留档工具（H5）

一个纯本地、无需联网的手机网页工具：在 PDF / 图片上手写签名或盖预置印章，导出带签名、印章和
签署时间的新文件，并在本机留存记录。**仅用于内部工作记录，不具备《电子签名法》可靠电子签名效力。**

## 怎么打开
- 电脑：直接双击 `index.html`，用浏览器打开。
- 手机：把整个文件夹（含 `vendor/`）传到手机，用浏览器打开 `index.html`；或部署到任意静态空间后访问链接。
- 无需安装、无需注册、文件不上传服务器，所有数据只存在本机浏览器。

## 使用步骤
1. **上传**：选择 PDF（叠加到第 1 页）或 JPG / PNG 图片。
2. **手写签名**：在底部画板书写，可「撤销一笔 / 清空」，点「添加到文件」；笔迹会自动保存，下次可用「用已存笔迹」。
3. **盖印章（可选）**：点「已阅 / 确认 / 本人签署」，红色圆章加到页面。
4. **摆放**：拖动签名/印章到目标位置，用「＋放大 / －缩小」调整大小，可「删除」。
5. **填写**：姓名（手填，非实名）、备注（可选）；时间自动生成并印在签名旁。
6. **导出留档**：生成新文件，显示原文件与导出文件的 SHA-256，点「保存导出文件」；记录进入「我的签署记录」。

## 文件清单
```
index.html            主程序（全部界面与逻辑）
vendor/               PDF 处理库（本地，离线可用）
docs/superpowers/specs/ 设计文档
```

## 已知限制
- 仅叠加 PDF 第 1 页；多页 PDF 请拆分后分别处理。
- 不支持 Word（.docx）。
- 签名、姓名为手填，无实名/人脸/CA 存证，不能用于正式法律合同举证。
- 记录只存当前浏览器；清理浏览器数据会删除本地记录。
- PDF 依赖本地 `vendor/` 库，需连同文件夹一起使用；个别内置浏览器对 `file://` 本地脚本有限制，
  此时 PDF 会提示不可用，请改用普通浏览器（Safari/Chrome/系统浏览器）打开，或把文档截图/转成图片上传。
  图片（JPG/PNG）在任何环境都可直接使用。

## 验证情况
- 图片链路（上传→手写→盖章→时间戳→导出→哈希→记录→下载）已在浏览器实测通过。
- PDF 叠加（pdf-lib embedPng/drawImage/save）与 pdf.js 渲染已做冒烟验证，产出合法 PDF。
